# Release notes

Modified 2026-10-23.

## v0.1.0-alpha.1 source baseline

The initial experimental source release introduced local validation of the three
Xbox executable inputs, a pinned ReXGlue SDK build, local module generation and
isolated saves. Career coverage reaches Sportsman; later progression is unverified.

## Enhanced edition

Adds configurable internal resolution, optional user-supplied texture packs and experimental temporal graphics modes, alongside
DirectInput wheel support, wheel/controller switching, separate pedal/shifter
bindings and SDL DualSense vibration/adaptive-trigger controls.
Optional Project Forza Plus 4 support uses separately prepared data and saves.

Known issues include blank car thumbnails, career-menu visibility and frame
pacing. Hardware feedback compatibility and full gameplay coverage remain
incomplete. See [Current status](STATUS.md).

The release contains source and build tooling only: no game data, textures,
generated translation, saves, SDK binaries or game executable. The project
retains GPL-3.0-only; supply inputs from your own legally obtained game copy.
